# The City: Codex guidance

Read `CLAUDE.md` before working in this repository. It contains the project's
commands, architecture, verification requirements and operating constraints.
Follow that guidance when working with Codex as well.

Before changing the corresponding area, read and follow:
- `.claude/rules/app.md` for SwiftUI, RealityKit, theming and companion code.
- `.claude/rules/office-core.md` for OfficeCore, CLI streams and fixtures.
- `.claude/rules/assets.md` for asset pipelines and bundled resources.

Claude CLI references describe the application's current integration. Do not
change its runtime provider or GitHub automation as part of agent setup alone.

Use the Slaymish GitHub identity for this personal repository. When using `gh`,
select its credentials per command rather than changing the default work account.
